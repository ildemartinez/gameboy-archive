# Editorial image placeholders

These lightweight SVG cards mark places where a photograph or explanatory diagram would help readers. Each file is named for its intended subject and says what to replace it with. Replace the referenced SVG with a final visual (or update the Markdown path) when an original, licensed, and appropriately sourced asset is ready.

The cards are intentionally generic and are not photographs of Nintendo hardware. Keep the same aspect ratio when replacing them where practical. Existing licensed photographs on the Basic Colors page and the existing family image on the home page are left in place.

## Categories

- `family/` — model and historical context.
- `dmg-01/` — console views, physical details, and motherboard revisions.
- `cartridges/` — cartridge formats and internal construction.
- `reference/` — explanatory hardware diagrams.
